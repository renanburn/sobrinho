# Armadilhas

O que quebrou ou enganou, e como evitar. A skill escreve aqui quando algo dá errado e lê este arquivo antes de desenhar a próxima tela.

Este arquivo só cresce: armadilha resolvida de vez ganha uma linha embaixo dizendo como.

Formato de cada entrada:

```
## AAAA-MM-DD · <tela ou componente>

- **<nome curto da armadilha>.** Sintoma: o que apareceu. Causa: por que aconteceu. Regra: o que fazer daqui pra frente.
```

Formato preenchido em [`exemplo/armadilhas.md`](../exemplo/armadilhas.md).
